# CodiError

Esta carpeta contiene `Error.html`, una pequeña página para demostrar la captura de dos errores con JavaScript.

## Cómo probarlo y hacer las capturas

1. Abre `Error.html` en el navegador.
2. Abre las herramientas de desarrollador con `F12` y entra en la pestaña **Consola**.
3. Pulsa **Lanzar error de código**. La página mostrará un mensaje y la consola registrará `ERROR 1`.
4. Selecciona **Opción incorrecta** y pulsa **Comprobar opción**. La página mostrará el motivo y la consola registrará `ERROR 2`.
5. Haz una captura de cada prueba donde se vean el mensaje de la página y el mensaje de la consola.
6. Guarda las dos imágenes en esta carpeta, por ejemplo como `ErrorCodigo.png` y `OpcionIncorrecta.png`.

Los errores son intencionados y se capturan con `try...catch`; no deberían cerrar ni bloquear la página.
